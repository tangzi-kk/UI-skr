# POLARIS · ORBIT K80 — 独立交互预览

该目录保存**图标优先、文字极简、空间触控式**的 ORBIT K80 单文件 HTML 设计预览，用于体验与设计评审。

### 如何体验

1. 打开 [polaris-orbit-k80.html](./polaris-orbit-k80.html)。
2. GitHub 文件页点击 **Download raw file** 下载，然后用手机或桌面浏览器打开。
3. 左侧四图标切换快捷内容；底部长胶囊切换效率/灵气/看板；长按圆胶囊并滑到花瓣目标后松手；右下小圆可拖动。

### 与正式工程的边界

- 该文件内嵌 CSS、JavaScript、图形与演示内容；无额外构建步骤、外部资源或网络依赖。
- 预览中的新建、编辑、心情等数据仅保存在浏览器 localStorage 中，**不会同步飞书**。
- 当前 Android 正式入口仍为 `mobile-app.html`；本次上传没有替换它或修改 Mac MVP。
- 真机滑动手感、触觉振动是否可用因设备和浏览器而异。
