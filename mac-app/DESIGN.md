# 年度看板（年度日历）DESIGN.md · 视觉契约与设计系统

> 本文档为年度日历前端界面的唯一真实设计源（Single Source of Truth）。  
> 任何 AI 编程代理或前端切片开发，必须优先遵守本设计契约，严禁生成脱离本规范的 AI 模板化样式（如紫色 SaaS 渐变、泛滥卡片嵌套、浅灰看不清的正文字体、无脑发光按钮）。

---

## 1. 核心设计哲学 (Design Philosophy)

- **墨韵纸感，沉静工具**：模拟东方纸张的温润触感（暖白纸面 `#fdfcf9` + 沉静墨色 `#262b33`），而非冰冷廉价的通用后台。
- **高确定性与高密度**：信息呈现高度规整，注重日程密度的同时提供合理的呼吸感留白。
- **macOS 原生内敛感**：克制、快速响应，所有交互动画仅服务于状态反馈（展开、折叠、选中），拒绝手搓浮夸特效。

## 2. 调色盘与语义 Tokens (Color System)

### 2.1 基础材质与层级
- **画板底色 (Canvas)**：`#eceae5`（点阵网格 `--dot: #dbd8d1`）
- **纸张面板 (Sheet)**：`#fdfcf9`（边框 `--sheet-border: #d9d4cb`）
- **表头墨蓝 (Header)**：`#343b45`（高亮文字 `#f4f2ec`，浅态文字 `rgba(244, 242, 236, 0.62)`）
- **文字层级 (Ink)**：
  - **强墨 (Title/Primary)**：`#262b33`（极高对比度，确保一眼可辨）
  - **柔墨 (Body/Secondary)**：`#71767f`（属性、时间范围、辅助标签）
  - **淡墨 (Muted/Placeholder)**：`#a7abb4`（禁用、占位符，严禁更浅）

## 3. 字体与版式 (Typography)

- **字体栈**：优先调用 macOS 苹果系统字族：
  `-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Segoe UI", Roboto, sans-serif`
  （标题特殊强调可选 `--font-song: "Songti SC", serif`）
- **字阶阶梯**：
  - `11px` / `12px`：微标签、时间轴刻度、胶囊角标
  - `13px` / `14px`：默认正文、日程标题、表单输入框
  - `16px` / `18px`：弹窗标题、月份/周导航标题
  - `24px+`：统计大数字指标

## 4. 交互形态与布局组件 (Components & Layout)

### 4.1 快速创建气泡 (QuickCreatePopover)
- **自适应抽屉 (In-flow Tray)**：展开历史或常用预设时，采用容器内流式推挤动画，严禁使用遮挡输入或操作按钮的绝对定位浮层。
- **历史项交互**：
  - 点击左侧文本：仅填充标题输入框。
  - 点击右侧分类胶囊：同时联动填充标题与分类单选值。
  - 严禁在按钮点击回调中调用无防抖的 `input.focus()`，避免陷入死循环。

### 4.2 阴影与边框 (Shadows & Borders)
- 常规卡片/按钮使用 1px 实体柔和边框：`1px solid #e4e0d8`。
- 浮层阴影采用多层弥散软投影：
  - 气泡弹窗：`box-shadow: 0 10px 32px rgba(35, 45, 80, 0.14)`
  - 全屏模态窗：`box-shadow: 0 24px 64px rgba(30, 38, 60, 0.28)`

## 5. 反 AI 模板化防退化审查清单 (Anti-AI Checklist)

在任何前端提交前，必须逐项自查：
1. [ ] **无卡片堆叠**：是否出现无意义的“卡片套卡片”？容器层级是否精炼？
2. [ ] **无图标泛滥**：是否所有小按钮、列表项、小标题前都被无脑加了 Emoji 或 Feather 图标？（仅保留最具语义的 1~2 个关键图标）
3. [ ] **无无脑渐变**：背景是否干净？按钮是否保持纯净实体色，没有漂浮的紫色或彩虹渐变？
4. [ ] **对比度合规**：正文文字对比度是否达到 WCAG AA 标准？辅助文字是否依然清晰可辨？
5. [ ] **原生响应**：交互是否有即时反馈？是否支持原生键盘快捷键（Enter 提交，Esc 关闭）？
